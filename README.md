# MyCloset
Una web app que permite gestionar el vestuario personal de manera intuitiva. La aplicación permite:
- 👗 Armar outfits diarios combinando prendas del clóset virtual.
- 📌 Guardar combinaciones con etiquetas para diferentes estilos y ocasiones.
- 🔄 Modificar y ajustar outfits según las necesidades del usuario.

# Tareas realizadas del backend
- Modelado de entidades
- Autenticación y Autorización(JWT, Oauth2.0, Google)
- Persistencica de session via cookie
- Construcción de servicio REST
- Pasarela de pago
- Automatización de notifaciones
- Documentación
